# Mark Anthony D. Carcha — Personal Portfolio

## Setup for GitHub Pages (`mrkcarcha/markcarcha`)

1. Place `index.html` at the root of the repository (`index.html`).
2. Create an `images/` folder next to `index.html` and save your 7 photos with these exact filenames:
   - `images/profile.png`
   - `images/youth-summit-2025.jpg`
   - `images/pfc-assembly-2026.jpg`
   - `images/graduation-day-2026.jpg`
   - `images/intramurals-2026.jpg`
   - `images/mental-health-2026.jpg`
   - `images/festival-of-talents-2026.jpg`
3. Upload `index.html` and the `images/` folder to GitHub, then enable **GitHub Pages** in **Settings → Pages** (`main` branch, `/ (root)` folder).
